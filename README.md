# Luxskingluta GLOWUP — Single-page website

Website satu halaman memanjang yang bisa dijelajahi dengan scroll, tanpa halaman loading khusus. Di HP, halaman memenuhi lebar layar. Di komputer, tampilan dipusatkan dengan lebar menyerupai layar HP.

## File
- `index.html` — struktur halaman dan konten
- `style.css` — desain responsif, tampilan mobile-first, animasi ringan
- `script.js` — menu, pencarian/filter katalog, FAQ, dan tombol WhatsApp

## Cara menggunakan
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk melihat preview.
3. Untuk GitHub Pages, unggah `index.html`, `style.css`, dan `script.js` ke repository.
4. Ganti ilustrasi produk dengan foto asli, serta isi harga/deskripsi sesuai informasi resmi produk.

## Pengaturan WhatsApp
Nomor admin ada di bagian awal `script.js` pada variabel `WHATSAPP_NUMBER` (format internasional tanpa `+` atau spasi).

## Sebelum dipublikasikan
Ganti teks placeholder pada deskripsi produk dan testimoni dengan informasi serta ulasan asli. Jangan mencantumkan klaim manfaat, keamanan, BPOM, atau halal kecuali sudah dapat diverifikasi.
